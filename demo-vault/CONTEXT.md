# KM Domain Vocabulary

- **Authoritative source** — approved artifact defining current truth.
- **Operational record** — progress, evidence, or workflow state.
- **Derived knowledge** — summary/wiki representation that points back to sources.
- **KM Sync Loop** — meaningful change -> durable Markdown -> refreshed retrieval index.
- **KM Export Loop** — instruction -> retrieval -> bounded context -> requested output -> review/write-back.
