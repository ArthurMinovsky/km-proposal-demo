# KM Proposal Demo

This disposable vault demonstrates a Markdown-first KM substrate. Markdown is the source of truth; the MCP search index is derived and rebuildable.

## Demo flow
1. Search for a requirement.
2. Read the exact source note before acting.
3. Draft new agent knowledge under `proposals/`.
4. Review before promoting content into an authoritative note.
5. Search again to show the refreshed index.
